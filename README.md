# SGSU AI-Native University Platform (NEXORA)

**Scope Global Skills University (SGSU)** — Conference Demonstrator & AI-Native Academic Intelligence Platform.

## Core Architecture
- **Curriculum Graph & Learning Outcomes**: Strict anchoring to explicit outcomes (`LO1`, `LO2`, `LO3`, `LO4`) and prerequisites (`P1`, `P2`).
- **Unified Evidence Model**: Single source of truth across all 4 connected experiences.
- **Prior-Weighted Mastery Estimator**: Honest live-student tracking (LO1: 88%, LO2: 74%, LO3: 81%, LO4: 41% Needs Attention).
- **Cohort Arithmetic**: Section 5-A (61% weak, 35 students), Section 5-B (54% weak), Combined 58% weak across 114 students.
- **AI Gateway & Deterministic Fallbacks**: Course-grounded explanations, automated 10-minute remedial re-teach segments, and Senate academic recommendation drafting.

## 4 Connected Experiences
1. **AI Teacher Studio**: Lecture Builder (Draft $\to$ Review $\to$ Approve $\to$ Publish), Class Insights, Remedial Recommendations.
2. **AI Smart Classroom**: Live synchronized slides, concept polls, in-class prompt dispatcher, and 5-question exit quiz.
3. **Student Intelligence**: Continuous outcome mastery, "Your Learning Gap" 3-step action panel, personalized practice, and grounded AI tutor.
4. **University Intelligence**: Multi-section recurring gap analysis, prerequisite mathematics diagnostics, non-surveillance privacy compliance, and immutable audit ledger.

## Conference Demonstrator Runner (`/demo`)
Includes an interactive 8-step live state tracker, instant scripted quiz autofill (`D03`), and one-click benchmark data reset (`D01`).

## Tech Stack
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Lucide React icons
- **State & Architecture**: Reactive event bus, prior-weighted Bayesian estimator, WebSocket state protocol
